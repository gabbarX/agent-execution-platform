# Milestone Docs

One file per milestone: `M<N>-<topic>.md`. Each covers:

- **What was built** — components, APIs, schema changes.
- **Concepts taught** — the ideas behind the code, in plain language,
  written so the owner can re-derive them from this doc alone.
- **Demo** — link to `demos/m<N>.md`.
- **What we'd do differently** — honest retrospective notes.
