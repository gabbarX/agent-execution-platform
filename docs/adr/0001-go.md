# 0001. Build the platform in Go

**Status:** accepted
**Date:** 2026-11-21

## Context

Language choice for the whole platform. Alternatives: TypeScript (fastest
if you know JS; reads full-stack rather than infra) and Python (easiest to
read while learning; asyncio is a weaker fit for a scheduler-heavy
system).

## Decision

Go 1.27 for everything, including the agent SDK (owner's pick).

## Consequences

Native fit for the domain — Temporal, Kubernetes, Docker, and Firecracker
tooling are all Go; goroutines/channels map directly onto schedulers and
worker pools; single-binary deploys. Cost: the owner is learning Go
alongside the concepts, so early milestones budget time for language
teaching. Revisit: never for the platform; a Python SDK could be a
post-M7 stretch.
