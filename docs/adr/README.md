# Architecture Decision Records

One numbered file per decision that had a real alternative
(`NNNN-short-slug.md`, immutable once accepted — supersede, don't edit).
Keep each under half a page.

## Template

```markdown
# NNNN. Title

**Status:** accepted | superseded by NNNN
**Date:** YYYY-MM-DD

## Context
What situation forced a choice, and what the live alternatives were.

## Decision
What we chose, in one or two sentences.

## Consequences
What this buys us, what it costs us, and what would make us revisit it.
```
