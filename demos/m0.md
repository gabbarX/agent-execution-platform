# Demo M0 — Repo Foundation

Assumptions: Windows with Go 1.27+, PowerShell 7, repo checked out at its
root. golangci-lint installs on demand via the instruction the gate prints
if it's missing.

## 1. The quality gate passes

```powershell
pwsh -File scripts/check.ps1
```

Expected output (abridged):

```
==> gofmt
==> go vet
==> golangci-lint
0 issues.
==> go test
ok      github.com/gabbarX/agent-execution-platform/internal/version
==> go build
ALL CHECKS PASSED
```

Exit code 0.

## 2. The test suite, verbosely

```powershell
go test ./... -v
```

Expected output (abridged):

```
=== RUN   TestVersionString
--- PASS: TestVersionString (0.00s)
PASS
ok      github.com/gabbarX/agent-execution-platform/internal/version
```

## 3. Code intelligence index is healthy (optional tooling)

```powershell
codegraph status
```

Expected output (abridged): `Project: ...agent-execution-platform`,
non-zero `Files` / `Nodes` counts, no errors.
